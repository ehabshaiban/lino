# shadpo-master

COOKIES LINO theme project extracted from the supplied monolithic HTML source and organized into the requested Salla/Twilight-style structure.

The original source is preserved as `src/views/pages/index.twig` and the extracted runtime is preserved under `src/assets/js/`.


## Salla compatibility fix
- `twilight.json` uses the current Twilight metadata structure with bilingual `name`, `features`, `settings`, and `components`.
- The project is packaged with `twilight.json` at the archive root for direct theme-file inspection.
- The standalone loading screen and its entry message have been removed.
